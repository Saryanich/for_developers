IT Global — управление данными Firestore

Ручной просмотр и выборочное удаление документов проекта glob-data.

Важно: удаление необратимо. Сначала сделайте резервную копию. Firestore не имеет обычных папок и файлов: документы могут содержать подколлекции. Подколлекции нужно проверять отдельно, указав путь к ним. Коллекция global_ids и все пути внутри неё заблокированы для удаления. Файлы Firebase Storage эта страница не удаляет.

Вход администратора

Коллекции, подколлекции и документы

Введите путь к коллекции. Примеры: users, arcade_games/ID_ИГРЫ/ratings, users/UID/подколлекция. Путь должен оканчиваться на коллекцию. Вложенные подколлекции не обнаруживаются автоматически — укажите их путь вручную.

Выберите путь и загрузите документы.

Загружаются максимум 100 документов за раз. Для users первой строкой каждого документа отображается email. Удаление документа из users не удаляет соответствующую учётную запись Firebase Authentication. Для реального удаления коллекции нужно удалить все документы и отдельно проверить подколлекции.
